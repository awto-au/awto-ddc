# RTD2795T (RL6449) MCU: the 8051 core

Facts as of 2026-11-05. Confidence tags per awto-dan `docs/embedded/reversing/README.md`: [confirmed] read in source/binary, [likely] inferred, [measure] to be measured on hardware (diag block, #25 follow-up).
Detail and evidence: #24 (memory-map review, Keil map comparison), #19 (ISR priorities), #23, awto-au/awto-sdcc#6.

## Core
- **Synopsys DW8051 MacroCell** [confirmed]. Keil target `Device (DW-8051) Vendor (Synopsys) Cpu (IRAM(0-0xFF) … MODDP2)` (SDK `STD_FW_1P.Uv2`; same in public SDK copies, e.g. `Llong1/avita_rtd2776` `STD_FW_MtP.Uv2`).
- 4 clocks per machine cycle (DW8051), not 12T, not 1T [likely].
- MCU clock ≈ 88 MHz: M2PLL 351 MHz, `_FLASH_CLK_DIV _DIV_4` ("Flash = 44M, MCU = 88M", `Kernel/Common/Scaler_Option.h:655`), `_MCU_CLK_DIV _DIV_1` (`:724`) [likely, measure]. Dividers: `0xFFEE[5:2]` mcu, `0xFFED[5:2]` flash.
- Dual DPTR: `DPS` at SFR 0x86 (DS80C320 style, Keil `MODDP2`; old firmware toggles it in copy loops) [confirmed]. SDCC mcs51 does not emit it; hand asm only.
- MOVX stretch: `CKCON` (SFR 0x8E) `MD[2:0]=0` → MOVX = 2 cycles (`ScalerMcu.c:143-146`) [likely, measure].
- Code runs through a flash cache (`0xFDA0`); cache misses dominate timing more than instruction choice [likely].

## Internal RAM: 256 B total [confirmed]
`IDATALEN EQU 0100H` (`Kernel/Common/STARTUP.a51:27`); old firmware clears 0x01-0xFF, `SP=0x81`.

| Range | What | Notes |
|---|---|---|
| 0x00-0x1F | register banks 0-3 (R0-R7 ×4), selected by PSW RS1:RS0 | unused banks are plain RAM |
| 0x20-0x2F | bit-addressable (128 bits) | SDK `bit` flags |
| 0x30-0x7F | general | direct addressing (`mov a,0x45`, 2 B) |
| 0x80-0xFF | indirect only (`@R0/@R1`, stack) | direct 0x80-0xFF = SFRs |

- Keil original (same SDK generation, public `Ambient-Sensor-Explore/Output/RL6432_Project.m51`): data = 85.3 B incl. all 4 register banks, bits 0x20-0x28, DATA 0x29-0x49, IDATA 0x4A-0x54, stack from 0x55 [confirmed].
- SDK ISR register banks (`using`): EXINT0 bank 1 (537 callees), EXINT1 bank 2, WD bank 3 [confirmed]. Our SDCC port drops them (`keil2sdcc.py DROP_USING`): ISRs push R0-R7 instead; banks 1-3 hold DSEG.
- Our SDCC build (2026-11-05, main 1908a50): DSEG 13 B, overlaid locals DDOVL0/1, OSEG 6 B (lib `__memcpy`), **22 B direct free**; stack 0x80-0xFF, worst case 100/128 B (`scripts/fw_stack.py`). Pressure = SDCC spill slots (~510 B before overlay); Keil keeps those in registers.

## XDATA (64 KB address space)
- 0x0000-0xFEFF: scaler register file, memory-mapped (with `0xFFFC[4]` remap) [confirmed]. Pages C0-D0 hold ~1100 registers.
- **On-chip XRAM 8 KB: 0xD700-0xF6FF** (`RL6449_Gen_Option.h:72-73`; Keil `XDATA(0XD700-0XF6FF)`) [confirmed], 2-cycle MOVX.
  - DDC/EDID RAM windows at 0xE080 / 0xE280 / 0xE480 / 0xE680 (256 B each, D0-D3), movable +0x100 via `0xFEB1[3:0]`.
  - Our build reserves 0xF6E0-0xF6FF for the diag block (#25 follow-up).
- 0xFExx-0xFFxx: MCU registers (ports, I2C/DDC slave `0xFF2x`, watchdog `0xFFEx`, bank select **0xFFFF**).
- No other free SRAM [confirmed]: flash-cache SRAM has only a debug port (`0xFDC7-0xFDC9`).

## Code: banked flash
- 64 KB code space, all of it banked: bank select = XDATA **0xFFFF** (write), 16 banks of 64 KB [confirmed].
- Our layout: common area 0x0000-0x4FFF copied into every bank; banked code from 0x5000. Cross-bank calls via `fw/sdcc/bank.asm` (`__bs_call`/`__bs_ret`, like Keil `?B_SWITCH`).
- Banks 14-15 = settings and gamma data (never written by our image).
- Simulation: µCsim `memory create banker xram 0xffff 0x0f rom 0x0000 0xffff` models it exactly (`scripts/fw_sim.py`, #10).

## Interrupts
- Vectors 0x03 EXINT0 (HDMI/DP), 0x0B T0, 0x13 EXINT1 (DDC-CI/debug slave), 0x1B T1, 0x23 UART, 0x2B T2 (1 ms tick), 0x43 WDT [confirmed, `fw_build.py write_vectors`].
- Priority: `IP` (0xB8) and `EIP` (0xF8), no IPH; EIP never written. `IP=0x81` raises EXINT0, `IP=0xA0`/PT2 raises Timer2 (#19) [confirmed].

## Access cost (DW8051, per access) [likely, measure]
| Kind | Code | Cycles |
|---|---|---|
| DATA `mov a,dir` | 2 B | 2 |
| IDATA `mov r0,#; mov a,@r0` | 3 B | 3 |
| XDATA `mov dptr,#; movx a,@dptr` | 4 B | 5 |

5 µs delay loop (`ScalerMcu5usDelayCalc`), from SDK comments (`avita_rtd2776 ScalerMcu.c:2147`): cache off `(24+32+80*(N-1))/(McuClk*2)`, cache on `(52+12*(N-1))/McuClk`.
