# Sim CPU model (fast core, #162 step 1)

- Switch: `--cpu dw8051|8052` (fw_sim, fastcore_check), env `AWTO_SIM_CPU`; default `dw8051` (gates, sim_live, tests). Logged at sim start (`sim CPU model: ...`).
- `8052`: ucsim -t 52 classic cycles, fixed clock; the only mode `fastcore_check.py diff|fuzz|diffbus|gates` accepts (lockstep vs ucsim, exact cycle counts).
- `dw8051`: `fastcore_check.py timing` (no ucsim). Tables are data: `scripts/dw8051_model.json`, generated by `scripts/dw8051_model.py --write` (gate `dwmodel` = `--check`). awto-sdcc#67 (RL6449 ucsim) can load the same JSON.

## Clock per phase (`scripts/sim_clock.py`, from the registers the firmware writes)
- `f_cpu = source / FFED[5:2] / FFEE[5:2]`; source = M2PLL if FFED[1] else crystal domain (0x0009[3]: 0 crystal 14.318 MHz, 1 IOSC 28 MHz).
- M2PLL = crystal x (0x01E0 + 2) / ((0x01E1[3:0] + 2) x O), O = 2 x 0x01E1[5:4] or 1.
- Resulting: reset 7.16 MHz (FFED reset /2), `ScalerMcuInitial` crystal 14.318 MHz, M2PLL 87.7 MHz (351 / 4), power saving IOSC 28 MHz.
- Flash clock = source / FFED[5:2] / FFE9[3:0]; CPU clk per flash clk = FFE9[3:0] / FFEE[5:2].

## Code fetch from the SPI flash (core, `flash_fetch` in the JSON)
- Cache off (FDA0[0] = 0, reset state until `ScalerMcuInitial`): every byte read from the flash; sequential bytes continue one fast-read command.
- Cache on: 16 B lines (regdb FDA2..FDAF resolve [7:4]), 2-way LRU, invalidate on FDA1[0].
- Stall = flash clk x CPU clk per flash clk - the base byte cycles. Flash clk: command 40 (0x0B: 8 opcode + 24 address + 8 dummy), 8 per byte (1 bit).
- ASSUMED (no source): 2 KB cache (regdb FDA1 size_div: "minimum 128x2"), 1-bit reads. Result is insensitive to the cache size (64 -> 1024 sets: +-5 ms at first pass).
- Not modelled: MOVC data reads through the cache; flash common-instruction halts in wall / fw time (`FlashHalt` charges only the WDT); Timer2 stop during a halt (FFEE[6] mcu_peri_non_stop = 0).
